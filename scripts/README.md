# SNP Project Scripts

This folder contains the notebooks used for SNP processing and analysis in the Dipteryx alata project.

## Contents

- `gatk_baru.ipynb` — main workflow for read alignment, variant calling, and filtering using GATK.
- `annotation.ipynb` — functional annotation of variants and preparation of final results.

## Organization

The scripts in this directory are executable versions of the project's bioinformatics pipeline and can be used as a reference for running the main analysis steps.

## Notes

- Raw data, reference files, and large output files are not stored in this directory.
- Make sure the required dependencies and input paths are configured before running the notebooks.
- For general project context, see the main README at `../README.md`.
